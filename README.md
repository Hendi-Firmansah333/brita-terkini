# KabarKini — Berita & Pengumuman

Proyek front-end sederhana menggunakan HTML, CSS, dan JavaScript untuk latihan Software Configuration Management (SCM) dan Git.

## Fitur
- Desain modern dan responsif
- Navigasi desktop dan mobile
- Daftar berita contoh
- Pencarian berita dan filter kategori
- Daftar pengumuman
- Form email demo (belum terhubung ke backend)

## Menjalankan di VS Code
1. Ekstrak folder proyek.
2. Buka folder `berita-modern` di VS Code.
3. Buka `index.html` langsung di browser atau gunakan ekstensi Live Server.

## Catatan
Konten dan tanggal pengumuman merupakan data contoh. Sesuaikan sebelum dipakai untuk informasi sungguhan.
